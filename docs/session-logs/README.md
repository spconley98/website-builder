# Session Logs

All session logs and context-transfer handoffs live here.

Required layout:

```text
docs/session-logs/sean/YYYY-MM-DD-HHMM-short-topic.md
docs/session-logs/matt/YYYY-MM-DD-HHMM-short-topic.md
```

Rules:
- Sean-owned sessions go under `docs/session-logs/sean/`.
- Matt-owned sessions go under `docs/session-logs/matt/`.
- Do not create session logs under `docs/project/`, `docs/research/`, or ad hoc daily-note folders.
- Matt's agent should put proposed shared-memory changes in Matt's session log unless Sean explicitly
  approves editing `MEMORY.md`.
